\## Задача 1



\### Текст задачи



Найти наибольшую и наименьшую цифры в записи данного натурального

числа. 



\### Алгоритм решения



Предикат start запрашивает целое неорицательное число,после чего вызывает предикат digits(Number, Max, Min) который рекурсивно находит максимальную и минимальную цифры в неотрицательном целом числе. Если число однозначное, то Max и Min равны этому числу. Если число больше 9, то выделяется последняя цифра (LastDigit = Number mod 10), а оставшаяся часть (Number // 10) передаётся в рекурсивный вызов digits(Remainder, MaxRemainder, MinRemainder), после чего Max вычисляется как максимум из LastDigit и MaxRemainder, а Min — как минимум из LastDigit и MinRemainder. Рекурсия продолжается, пока не будет достигнуто однозначное число, после чего значения поднимаются обратно, последовательно сравнивая цифры.В конце предикат start выводит максимальное и минимальное.

\## Задача 2



\### Текст задачи



Определить количество нечётных отрицательных элементов в списке целых

чисел. 



\### Алгоритм решения



Предикат start запрашивает список целых чисел, после чего вызывает предикат count(List, Count), который подсчитывает количество нечётных отрицательных элементов в списке целых чисел. Сначала определяется вспомогательный предикат is\_odd\_negative(X), который проверяет, что число X меньше нуля и его остаток от деления на два не равен нулю, то есть число отрицательное и нечётное. Затем в основном предикате count(List, Count) используется встроенный предикат include(is\_odd\_negative, List, OddNegatives), который проходит по всем элементам исходного списка List, применяет к каждому проверку is\_odd\_negative и собирает в новый список OddNegatives только те элементы, для которых проверка оказалась истинной. После этого предикат length(OddNegatives, Count) вычисляет длину полученного списка, которая и является искомым количеством нечётных отрицательных элементов.Предикат start выводит количество нечетных неотрицательных элементов списка.
